## Supplementary Materials for *Non-intrusive Spectral Submanifold Reduced-Order Modeling of Geometrically Nonlinear Rotating Structures Considering Coriolis and Centrifugal Effects*

This repository provides the mesh or CAD files for the models used in this paper to facilitate reproducibility and future research.

The uploaded .nas files contain the mesh topology. Except for the fan model, the elements in these files are represented by 20 nodes. For the finite element analysis in this paper, they are extended to 27-node hexahedral (Hex27) elements. Thus, although the .nas files contain only 20-node elements, the actual finite element calculations use Hex27 elements.
